# Luna AI

Luna is an SMS-native agentic travel assistant.

Luna is not a chatbot. Luna is a persistent travel operator that lives inside SMS, remembers user context, manages multi-step workflows, and proactively acts on behalf of the user.

**Current milestone:** v0.0.1 — Local FastAPI skeleton.

---

## Architecture overview

```
luna/
├── main.py            # FastAPI app entry point
├── gateway/           # Twilio SMS interface (v0.0.3)
├── orchestrator/      # Core 11-step runtime loop (v0.0.2)
├── workflow/          # Workflow engine + state machines (v0.0.4)
├── reasoning/         # Claude API integration (v0.0.3)
├── tools/             # Tool abstraction layer + mock tools (v0.0.5)
├── memory/            # Six-segment memory model (v0.0.4)
├── confirmation/      # Pending confirmation store (v0.0.6)
├── composer/          # SMS Response Composer (v0.0.4)
├── safety/            # Safety and policy enforcement (v0.0.4)
├── scheduler/         # Proactive decision engine (v0.0.8)
└── events/            # Append-only event logger (v0.0.2)
```

Each package's `__init__.py` documents its full responsibility and the milestone it is implemented in.

## Local setup

### Prerequisites

- Python 3.11+
- Git

### 1. Clone and enter the repo

```bash
git clone <repo-url>
cd luna-ai
```

### 2. Create and activate a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

```bash
cp .env.example .env
```

For v0.0.1 no values need to be filled in. Twilio and Anthropic keys are not used until v0.0.3.

---

## Run the server

```bash
uvicorn luna.main:app --reload
```

The server starts at `http://localhost:8000`.

Auto-reload is enabled — the server restarts on any file change.
